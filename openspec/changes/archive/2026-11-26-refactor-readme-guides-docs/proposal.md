# Proposal

## Why

README, guides, and docs have drifted from the implemented feature set and each other: status labels are inconsistent (e.g. multi-host listed as complete in one place and partial elsewhere), some guides are stubs, and cross-references/links are stale. A consistency pass will make onboarding and feature status trustworthy.

## What Changes

- Normalize the README status section against implemented capabilities and OpenSpec specs.
- Expand or consolidate stub guides (`configuration`, `consistent-queries`, `leadership-transfer`, `observability`, `state-machine`, `troubleshooting`) into complete, accurate guides.
- Fix cross-references and links across `guides/` and `docs/`.
- Remove or archive obsolete doc fragments.
